# Diamond Dynasty

A tabletop baseball trading card game that uses real, physical baseball cards from any
manufacturer as the playable pieces — plus a web companion app that turns MLB stats into game
ratings, and hosts the rulebook, card lookup, roster builder, and score tracker.

- **Rules**: [`docs/RULEBOOK.md`](docs/RULEBOOK.md)
- **App**: [`app/`](app/) — see [`app/README.md`](app/README.md) to run it
